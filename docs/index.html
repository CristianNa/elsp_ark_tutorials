ELSP-ARK Tutorials

About these tutorials

This series of tutorials were prepared by IBFC as part of the Advancing Restoration Knowledge grants of the Endangered Landscapes and Seascapes Programme.

Their purpose is to provide restoration practitioners with an accessible analytical toolset to extract relevant information out of environmental DNA data.

While it is possible to follow through with little to no experience in R, adapting these to your own data will require basic know-how. There are many resources online to learn how to use R:

  • An Introduction to R is a great place to start.
  • Data Carpentry is another.
  • R for the rest of us provide a free course with videos (registration needed)
  • swirl is an R package that teaches you R, by using R.

Tutorial sequence

We have prepared four sessions:

  1. Session 0: Getting started? will walk you through the data preparation typically needed after bioinformatic analysis.
  2. Session 1: Diversity indices and regression will show you how to estimate various diversity indices, and analyse them through a linear regression.
  3. Session 2: Multivariate and indicator species analysis walks through an example of multivariate ordination analysis with distance-based Redundancy Analysis and Indicator Species Analysis.
  4. Session 3: Joint species distribution models provides an example of non-ordination multivariate analysis with joint species distribution models, specifically, HMSC.

How to use the tutorials

Each tutorials has explanatory text, blocks of code, data examples and plots. Download the data here, read through the text, and copy the code over to your own script, check that there are no errors, and that the outputs match.

When you are ready, adapt and apply the code to your own data.

You can also download the raw RMarkDown file, which contain both explanations and code, by clicking the grey square Code at the top right of each page, next to the title.

If you have any questions

If you have issues with the materials or questions, please don’t hesitate to contact us, we will try to help as best we can.

Data access and reuse

The data in this tutorial is freely accessible under a CC BY-NC-SA 4.0 license. If you would like to work on the data for your own research purposes, please contact Cristian Navarro Waggershauser.

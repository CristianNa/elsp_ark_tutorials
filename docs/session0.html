Session 0: From sequencing reads to community data

What this session produces

This session starts with an ASV read-count table, taxonomic assignments, a laboratory-to-field lookup, and sample metadata.

We will:

  1. Connect sequencing records to their taxonomic and sampling information.
  2. Inspect the process controls.
  3. Apply confidence, control-count, and relative-frequency filters.
  4. Construct community matrices and align their metadata.
  5. Explore sequencing depth and sample accumulation.

The final outputs are a filtered read-count matrix, presence–absence and relative-frequency matrices, and matching sample metadata.

3. Define taxonomic labels and sample types

Choose the most resolved available taxonomic label

An ASV may have a species assignment, a genus assignment, or only a higher-rank assignment. We use the first available name, starting with species and working towards kingdom.

Several ASVs can therefore share one taxonomic label. The resulting community matrix will describe these labels rather than individual ASVs.

asv_tax <- asv_tax %>%
  mutate(
    # Treat empty rank entries as missing before choosing a label.
    across(
      all_of(tax_ranks),
      ~ na_if(str_trim(.x), "")
    ),

    consensus_name = coalesce(
      species, genus, family, order,
      class, phylum, kingdom
    )
  )

4. Reshape the counts and attach taxonomy

A long table gives each ASV–laboratory-sample combination its own row. This structure makes it easier to join information and apply filters.

Zero counts are omitted from this long detection table. We will restore zeros when constructing the community matrix.

asv_long <- asv_tab %>%
  # Turn the laboratory-sample columns into identifier–count pairs.
  pivot_longer(
    cols = -asv_id,
    names_to = "lab_id_original",
    values_to = "reads"
  ) %>%
  filter(reads > 0) %>%

  # Attach corrected laboratory IDs and sample classifications.
  left_join(
    sample_key,
    by = "lab_id_original",
    relationship = "many-to-one"
  ) %>%

  # Attach one prepared taxonomy record to each ASV.
  left_join(
    asv_tax,
    by = "asv_id",
    relationship = "many-to-one"
  )

Define subtraction thresholds

For each full taxonomic rank profile, we take the largest count observed in any process control. This count will be subtracted from the corresponding field-sample count.

The deliberately introduced positive-control taxon is excluded from these thresholds.

This is the filtering rule used in this dataset. It does not establish that all contamination has been removed, and it does not account for differences in sequencing depth between controls.

control_thresholds <- controls %>%
  filter(consensus_name != positive_control_taxon) %>%
  group_by(across(all_of(tax_ranks))) %>%
  summarise(
    threshold = max(reads),
    .groups = "drop"
  )

Excluding the positive-control taxon from the thresholds does not remove its detections from field samples. That distinction is retained from the original workflow.

6. Filter the field-sample detections

Select the target group and confident assignments

Keep field samples assigned to Metazoa with a reported confidence score at or above the chosen cutoff. Records with missing confidence scores are not retained.

The semi_join() restricts the analysis to laboratory IDs represented in the study metadata, without adding metadata columns at this stage.

field_detections <- asv_long %>%
  filter(
    sample_type == "Field sample",
    kingdom == "Metazoa",
    confidence >= confidence_cutoff
  ) %>%
  semi_join(
    metadata_lab,
    by = "lab_id",
    na_matches = "never"
  )

Combine ASVs with the same assignment

Counts are aggregated within each laboratory sample before applying the taxonomic control threshold.

field_counts <- field_detections %>%
  group_by(
    lab_id, consensus_name,
    across(all_of(tax_ranks))
  ) %>%
  summarise(
    reads = sum(reads),
    .groups = "drop"
  )

Subtract the control threshold

The join uses the full rank profile. Matching missing lower ranks is intentional: an unresolved genus-level assignment can still match the same genus-level profile in the controls.

Assignments absent from the control table receive a threshold of zero.

field_corrected <- field_counts %>%
  left_join(
    control_thresholds,
    by = tax_ranks,
    na_matches = "na",
    relationship = "many-to-one"
  ) %>%
  mutate(
    threshold = replace_na(threshold, 0),

    # Clamp corrected counts at zero before removing non-detections.
    reads = pmax(reads - threshold, 0)
  ) %>%
  filter(reads > 0)

Remove low-frequency detections

Calculate each assignment’s fraction of the remaining target-group reads within its laboratory sample. Retain fractions strictly above 0.001, equivalent to 0.1%.

The denominator is the post-subtraction metazoan total, not the total number of raw sequencing reads.

asv_clean <- field_corrected %>%
  group_by(lab_id) %>%
  mutate(relfreq = reads / sum(reads)) %>%
  ungroup() %>%
  filter(relfreq > relative_cutoff) %>%

  # Recalculate totals after the low-frequency detections are removed.
  group_by(lab_id) %>%
  mutate(
    total_reads = sum(reads),
    relfreq = reads / total_reads
  ) %>%
  ungroup()

11. Create alternative community representations

The read-count matrix retains the corrected sequencing counts.

A presence–absence matrix records whether a taxonomic label has a retained detection. A relative-frequency matrix divides each row by its total retained read count.

Read frequencies are not direct estimates of organism abundance.

comm_pa <- vegan::decostand(
  comm_keep,
  method = "pa"
)

comm_relfreq <- vegan::decostand(
  comm_keep,
  method = "total"
)

stopifnot(
  all(comm_pa %in% c(0, 1)),
  all(abs(rowSums(comm_relfreq) - 1) < 1e-8)
)

12. Explore sample accumulation within habitats

Read-based rarefaction varies the number of reads within one sample. Here we change the sampling unit: we accumulate soil samples within each habitat.

For each habitat, iNEXT receives:

  1. The total number of retained soil samples.
  2. The number of those samples in which each taxonomic label was detected.

The detection frequencies come from the presence–absence matrix.

samples_by_habitat <- split(
  metadata_keep$sample_id,
  metadata_keep$treatment,
  drop = TRUE
)

inext_input <- purrr::map(
  samples_by_habitat,
  function(sample_ids) {

    mat <- comm_pa[sample_ids, , drop = FALSE]

    # Count detections across samples for each taxonomic label.
    freq <- colSums(mat)
    freq <- freq[freq > 0]

    # iNEXT requires the sampling-unit count as the first entry.
    c(nrow(mat), freq)
  }
)

# ELSP-ARK Tutorials Tutorials

This series of tutorials were prepared by [IBFC](https://www.inverness.uhi.ac.uk/research/institute-for-biodiversity-and-freshwater-conservation/) as 
part of the Advancing Restoration Knowledge grants of the [Endangered Landscapes and Seascapes Programme](https://www.endangeredlandscapes.org/).

**Website:**  
https://cristianna.github.io/elsp_ark_tutorials/

## Sessions

- Session 0: Getting started
- Session 1: Diversity indices and regression
- Session 2: Multivariate and indicator species analysis
- Session 3: Joint species distribution models

## Repository contents

- `index.Rmd`: website homepage.
- `session0.Rmd` to `session3.Rmd`: tutorial source files.
- `_site.yml`: shared website configuration.
- `data/`: tutorial input datasets.
- `build_site.R`: local rendering script.
- `docs/`: rendered website published through GitHub Pages.
